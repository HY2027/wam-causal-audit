scripts from the local FastWAM research workspace. It is not a copy of an entire
model, dataset, robot simulator or training repository.

The FastWAM-origin material is distributed with its existing MIT notice in
`LICENSES/FastWAM-MIT.txt`; existing third-party notices in source files are
retained. Scientific anonymity is not a reason to remove upstream attribution.

No blanket license has been added to the independently authored audit code
without the repository owner's choice. Public visibility alone does not grant
a general software reuse license. The owner should select an appropriate license
for that code before describing the package as an open-source release.

External checkpoints, simulation assets and third-party packages are not
redistributed here. Obtain them from their providers under their respective
licenses. Original file hashes and source-relative locations are recorded in
`provenance/source_export.json` for traceability.
